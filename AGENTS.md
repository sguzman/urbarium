# Urbarium — Agent Operating Guidance

Read [CONSTITUTION.md](CONSTITUTION.md), [docs/DATA.md](docs/DATA.md) and [docs/WORLD.md](docs/WORLD.md) before changes.

- Work within this independent public repository and the exact requested scope, on the existing `main` branch by default.
- Do not infer source accuracy or complete city coverage from a rendered mesh. Maintain provenance, uncertainty, legal reuse, and clear separation of observed geography from visual approximations.
- Preserve publicly reproducible core operation. No private paths, unpublished datasets, private services, confidential communications, personal commentary, or derived private text may be included in any publicly visible file, asset, issue, test fixture, commit or log. Exclude material of uncertain release status.
- Maintain the standalone ontology at `ontology/` and the public gallery index at `gallery/`. These describe documented public geographic examples; they are not authorization to process a queue or fetch entire geographic datasets.
- Work on Urbarium alone. **Do not modify Tarium's registry** without a separate direct owner instruction naming this repository and the specific membership action. Never enroll another project by association.
- Keep modifications narrow; inspect the current head and changed paths, preserve unrelated files, run appropriate automated tests and source/publication checks, and report actual verification outcomes.

These are repository-level instructions; implementation-specific constraints remain in the technical documentation.
