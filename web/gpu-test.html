Urbarium / GPU adapter test

This lightweight test checks which GPU backends Edge exposes. It does not load the 3D city, download geographic data or render a continuous animation.

The default test requests the low-power WebGPU adapter and checks WebGL2. This is intended to prefer your integrated AMD GPU rather than waking the RTX 3090. Browser selection is not guaranteed.

Ready. Report stays in your browser until you download it. No data is sent to a server.

Isolated Vulkan experiment. If this Edge window crashes, close it; your normal Edge profile is unchanged.
