# Urbarium public gallery

[Visit the interactive Downtown Los Angeles pilot](https://sguzman.github.io/urbarium/) · [Machine-readable gallery index](index.json)

The gallery indexes existing independently public demonstrations. The Downtown Los Angeles scene includes Downtown, Little Tokyo / Arts District, and I-110 / Westlake work areas. These are regional processing/viewer sections, not completed city reconstructions.

Refer to [Urbarium's limitations](../README.md) and [data provenance](../docs/DATA.md) before interpreting 3D shapes. Road centerlines are not surveyed curbs; incomplete freeway representations are not shown as verified infrastructure. The gallery index records actual public demonstrations without importing third-party geographic data or private assets.
