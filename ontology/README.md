# Urbarium geographic ontology

[Machine-readable ontology](ontology.json) · [Region catalog](../regions/catalog.json) · [Source provenance and restrictions](../docs/DATA.md) · [Geometry contract](../docs/WORLD.md)

This ontology describes region work envelopes, provider-owned spatial features, provenance and geometry transformations that produce an interactive 3D viewer. WGS84 rectangles are selection bounds, not official boundaries. Source-feature identity, measured geometry and any visual approximation must be distinguished.

The ontology is a public, descriptive companion to the Rust pipeline and viewer. It neither bundles upstream data nor establishes complete building, transport or terrain fidelity. The listed Downtown Los Angeles sections refer to existing public prototype regions, not independently validated finished city specimens.
